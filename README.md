# Cassa Ventossa · Mochlos, Crete

Static website for the Cassa Ventossa holiday house in Mochlos, Crete.
Visitors choose their dates and book through Booking.com or Airbnb.

- `index.html`, `styles.css`, `main.js`: the site (no build step)
- `img/lg`, `img/sm`: web-sized photos

Run locally:

```bash
python3 -m http.server 5173
```
